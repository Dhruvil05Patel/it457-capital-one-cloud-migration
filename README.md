# Capital One: Cloud Migration to AWS

**IT457 – Cloud Computing Case Study Project**

A study of Capital One's transition from on-premises data centers to Amazon Web Services (AWS), focusing on cloud migration, architecture modernization, scalability, resilience, and operational efficiency.

## 📌 Project Overview

Capital One, a major financial services company, adopted a cloud-first strategy and migrated its infrastructure from traditional data centers to AWS. This case study examines the motivations behind the migration, the cloud architecture and services involved, the challenges encountered, and the resulting operational benefits.

The project will also include a practical cloud migration exercise based on the concepts studied in the case study.

## 🎯 Objectives

- Understand the motivation behind Capital One's transition to cloud infrastructure.
- Study the migration strategy and AWS services used.
- Analyze the architecture, scalability, resilience, and security considerations.
- Investigate the reported business and operational outcomes.
- Implement a hands-on cloud migration exercise.
- Evaluate the exercise using relevant performance, effort, and cost measurements.

## 🔍 Case Study Scope

The case study focuses on the following areas:

- **Cloud Migration:** Transition from on-premises data centers to AWS.
- **Architecture Modernization:** Adoption of cloud-oriented application architectures and managed services.
- **Scalability and Reliability:** Understanding elastic infrastructure and resilient application deployment.
- **Cost and Efficiency:** Examining infrastructure provisioning, operational efficiency, and cloud cost considerations.
- **Security and Governance:** Studying the considerations associated with operating cloud infrastructure in the financial services industry.
